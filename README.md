# Next Firebase Authentication

An authentication web application built with Next.js, React and TypeScript.

## About The Project

The application provides pages for sign in, sign up, forgotten password, account and administration, organized as Next.js app routes under `src/app/`.

## Built With

- Next.js 13 / React 18
- TypeScript

## Getting Started

### Prerequisites

- Node.js

### Installation

- Install the dependencies with `npm install`.
- Start the development server with `npm run dev` and open [http://localhost:3000](http://localhost:3000).
- Build for production with `npm run build`, then serve with `npm start`.
